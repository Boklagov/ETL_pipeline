# ETL Pipeline for Banking Data

Учебный Data Engineering проект, реализующий загрузку, очистку, обработку и перегрузку банковских данных между слоями DWH.

## Стек
- Python
- SQL / PLpgSQL
- PostgreSQL
- CSV
- DWH: stage, DS, RD, DM

## Что реализовано
- Загрузка сырых CSV-данных в stage-слой
- Перенос и обработка данных в DS-слое
- Создание витрин оборотов и остатков
- Формирование 101 формы
- Экспорт и импорт данных через Python
- Дедупликация записей
- Корректировка ошибочных значений
- Перегрузка данных в конечные витрины

## Структура проекта

- `1TASK/` — ETL-процесс загрузки и обработки банковских данных
- `2TASK/` — задачи по DWH: дедупликация, загрузка справочников, корректировка данных и перегрузка витрин
- `requirements.txt` — зависимости Python

## Запуск

1. Установить зависимости:
```bash
pip install -r requirements.txt
Восстановить базу данных из дампа, если используется задание 2.
Запустить SQL-скрипты в порядке, указанном в описании соответствующего задания.
